# Agents

Instructions for AI agents working in downstream projects that share this
repository's conventions. These instructions also apply to this repository.

When this `AGENTS.md` file is accessed through a symlink, resolve the symlink to
learn this repository's root. That root is the directory containing the resolved
`AGENTS.md` file. Paths written in this repository start from that root.

## Version control

Keep your edits unstaged. Leave staged work you did not make as staged, so it
stays apart from your edits. If I stage a change you made, do not unstage it,
and keep your following edits unstaged on top of that snapshot.

Do not commit. I may ask for help drafting a commit message, but I make the
commit myself.
